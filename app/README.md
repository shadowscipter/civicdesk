# CivicDesk frontend

This Vite application contains the CivicDesk Phase 1 management frontend. For the project overview, architecture, privacy boundaries, and roadmap, see the [repository README](../README.md).

```bash
npm install
npm run dev
npm run build
npm run lint
```

The interface uses fictional demonstration data only. It is not connected to Supabase and must not be used to store real personal information.
